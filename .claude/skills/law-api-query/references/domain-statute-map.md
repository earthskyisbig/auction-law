# 부동산 도메인 → 핵심 법령·쟁점 매핑

질문 도메인을 판별하면 이 표로 검색해야 할 법령·키워드·조문을 즉시 특정한다.
법령명은 `search --target law` 로 MST를 얻은 뒤 `body`로 조문을 확정한다.

## 1. 부동산경매 (법원경매 / 민사집행)
| 법령 | 핵심 쟁점·조문 |
|------|----------------|
| 민사집행법 | 경매절차, 매각조건, 배당순위, 인수주의/소멸주의, 매각불허가(§121·§123), 배당요구종기 |
| 민법 | 저당권(§356~), 유치권(§320), 법정지상권(§366), 전세권, 가등기담보 |
| 주택임대차보호법 | 대항력(§3), 우선변제권(§3-2), 최우선변제 소액보증금(§8), 배당요구 |
| 상가건물 임대차보호법 | 대항력, 우선변제, 환산보증금 기준 |
| 국세기본법 | 당해세 우선(§35), 조세채권과 배당순위 |
- 검색 키워드 예: `유치권 경매`, `법정지상권`, `대항력 우선변제`, `배당요구종기`

## 2. 공매 (온비드 / 체납처분)
| 법령 | 핵심 쟁점·조문 |
|------|----------------|
| 국세징수법 | 압류, 공매절차, 매각결정, 배분, 공매재산 명세 |
| 지방세징수법 | 지방세 체납 공매 |
| 국유재산법 | 국유재산 매각·대부 |
| 한국자산관리공사 설립법 | 온비드 위탁 공매 |
- 검색 키워드 예: `공매 배분`, `압류재산 매각결정`, `공매 대항력`

## 3. 매매 (일반 부동산 거래)
| 법령 | 핵심 쟁점·조문 |
|------|----------------|
| 민법 | 매매계약, 계약금·해약금(§565), 하자담보책임(§580), 위험부담 |
| 부동산 거래신고 등에 관한 법률 | 실거래 신고, 토지거래허가구역, 자금조달계획서 |
| 공인중개사법 | 중개보수, 중개대상물 확인·설명의무, 손해배상책임 |
| 부동산등기법 | 소유권이전등기, 등기의 효력 |
| 주택임대차보호법 / 상가임대차법 | 임차인 보호(임대인 지위 승계 등) |
- 검색 키워드 예: `계약금 해약금`, `하자담보책임`, `토지거래허가`, `중개사 설명의무`

## 4. 재개발 / 재건축 (정비사업)
| 법령 | 핵심 쟁점·조문 |
|------|----------------|
| 도시 및 주거환경정비법(도정법) | 조합원 자격(§39), 분양신청, 관리처분계획(§74~), 현금청산(§73), 정비구역, 청산금, 이전고시 |
| 빈집 및 소규모주택 정비에 관한 특례법 | 가로주택정비·자율주택·소규모재건축 |
| 도시재정비 촉진을 위한 특별법 | 재정비촉진지구 |
| 주택법 | 리모델링, 매도청구 |
- 검색 키워드 예: `재건축 현금청산`, `조합원 자격 다물권자`, `관리처분계획 인가`, `투기과열지구 조합원 지위 양도`
- 판례·법령해석례(expc) 병행 필수 — 조합원 자격/현금청산 다툼은 판례 의존도 높음

## 5. 청약 (주택공급)
| 법령 | 핵심 쟁점·조문 |
|------|----------------|
| 주택법 | 공급질서 교란행위(§65), 전매제한(§64), 사업주체 |
| 주택공급에 관한 규칙 | 청약자격, 순위, 무주택기간, 재당첨 제한, 특별공급, 부적격 |
| 공공주택 특별법 | 공공분양·나눔형 등 |
| 조세특례제한법 | 청약통장 소득공제 등 |
- 검색 키워드 예: `주택 전매제한`, `공급질서 교란`, `특별공급 자격`, `부적격 당첨`
- 규칙(주택공급규칙)은 `target=admrul` 또는 `target=law`로 확인, 세부는 자주 개정 → 시행일 확인

## 판별 힌트 (질문 → 도메인)
- "낙찰/배당/유치권/대항력/명도" → 경매
- "온비드/압류/체납/공매" → 공매
- "계약금/잔금/하자/중개/등기/토지거래허가" → 매매
- "조합원/관리처분/현금청산/분양자격/입주권/정비구역" → 재개발·재건축
- "청약/전매/특공/무주택/당첨/가점" → 청약
- 복합 질문(예: 재개발 구역 내 물건 경매)은 해당 도메인 모두 활성화.
