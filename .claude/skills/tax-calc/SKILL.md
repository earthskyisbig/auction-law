# tax-calc — 부동산 세액 확정 계산기

세무 계산의 환각(암산 오류·조건 누락)을 차단하기 위해 **역할을 분리**한다:

| 역할 | 담당 | 비고 |
|------|------|------|
| 사실관계 추출·분류 | LLM (tax-advisor) | 자연어 → 입력 JSON |
| 특례 판정 (결정 트리) | `scripts/engines/special_cases.py` | if-else 확정 로직 |
| 세액 연산 | `scripts/engines/*.py` | 100% 수학 연산 |
| 세율·기준값 | `rules/*.json` | 수치마다 근거 조문 + 검증상태 |
| 근거 조문 원문 확인 | law-api-query 스킬 | 미검증 경고가 뜬 값 갱신 |

## 사용 절차

1. **사실관계 추출** — 사용자 대화에서 아래 스키마의 JSON을 만든다. 스키마 예시:
   ```bash
   python .claude/skills/tax-calc/scripts/tax_calc.py --sample acquisition    # 취득세
   python .claude/skills/tax-calc/scripts/tax_calc.py --sample holding        # 보유세
   python .claude/skills/tax-calc/scripts/tax_calc.py --sample capital_gains  # 양도세
   ```
   각 필드의 의미는 `scripts/engines/*.py` 모듈 docstring에 정의되어 있다.
   **모르는 값은 지어내지 말고** 사용자에게 묻거나 "가정값"으로 명시한 뒤 경고에 반영한다.

2. **계산 실행** — 추출한 JSON을 파일로 저장 후:
   ```bash
   python .claude/skills/tax-calc/scripts/tax_calc.py --input _workspace/tax_facts.json          # 사람용 보고서
   python .claude/skills/tax-calc/scripts/tax_calc.py --input _workspace/tax_facts.json --json   # 기계용 JSON
   ```
   입력 JSON에 `acquisition` / `holding` / `capital_gains` 키가 있는 세목만 계산된다(복수 가능).

3. **경고 처리 (필수)** — 출력의 `⚠ 확인 필요` 항목을 그대로 사용자 보고서에 옮긴다.
   - `미검증 수치 사용:` 경고가 뜨면 → **law-api-query로 해당 조문을 조회해 값을 검증**하고,
     확인되면 `rules/*.json`의 해당 항목 `verified` 필드를 갱신한다(갱신일 명기).
   - 조정대상지역 여부는 국토부 고시 사항(API 범위 밖) — 반드시 별도 확인 후 입력.

4. **보고** — 스크립트의 6단계 산출내역(①과세표준→⑥총부담세액)과 근거 조문을 그대로 인용한다.
   **스크립트 출력 숫자를 LLM이 재계산하거나 반올림해 바꾸지 말 것.**

## 판정 로직이 반영한 핵심 규칙 (2026-08 기준, wiki/tax 검증분)

- **취득세 중과** (§13의2): 법인 12% / 조정 2주택 8%·3주택+ 12% / 비조정 3주택 8%·4주택+ 12%.
  저가주택(시가표준 수도권 1억·비수도권 2억 이하) 중과 제외 — 단 **정비구역 소재는 제외 배제**(재개발 빌라 함정).
  일시적 2주택(3년 내 처분+사유)은 표준세율. 분양권 취득 주택은 **분양권 취득일 기준** 주택수 판정 경고.
- **양도세 다주택 중과 유예 종료**: 한시 배제는 **2026-05-09 양도분까지**(시행령 §167의3①12호의2).
  2026-05-10 이후 양도분은 중과(+20/+30%p, 장특공 배제) 원칙 적용. 경과조치(~2026-11-09) 경고 출력.
- **일시적 2주택 비과세** (§155①): 1년 경과 취득 + 3년 내 종전주택 양도 + 종전주택 자체의 §154① 요건.
  기한 도과는 §155⑱ 한정열거 사유(경매신청·공매·캠코·청산소송)만 용서 — **경매 하네스와 직결**.
  3주택→2주택 경로는 배제(대법원 2024두55426).
- **장특공**: 표2(보유·거주 각 연 4%, 최대 80%)는 **거주 2년 미만이면 표2 자체 배제 → 표1**(최대 30%).
- **종부세**: 공제 1세대1주택 12억/일반 9억/법인 0, 공정시장가액비율 60%, 3주택+ 중과 세율표(주택수 기준, 조정지역 무관),
  고령자+장기보유 세액공제 합산 80% 한도. 부부공동명의 특례는 9.16~9.30 신청 요건.
- **혼인합가 특례**: 10년 (§155⑤ 개정 2024.11.12) — **양도일이 개정 전이면 구법 5년** 자동 분기.
  동거봉양 10년·60세(§155④), 상속주택 특례 선순위·동일세대 배제(§155②③)도 원문 검증분 반영.
- **생애최초 감면**: 일반 200만 / 소형·저가·인구감소지역 300만 한도, 12억 이하, 2028.12.31 일몰,
  3년 내 매각·임대 시 추징(지특법 §36의3 — 2026-08-16 원문 검증).

## 한계 (정직하게 알릴 것)

- 대부분의 세율·기준값은 law-api 원문 검증 완료(2026-08-10 위키 + 2026-08-16 직접 조회). **잔여 미검증(`참고값`) 항목**: ① 증여 중과 기준금액 3억(시행령 §28의6) ② 취득 농특세 중과 시 0.6%/1.0% 산식·서민주택 85㎡ 정의(농특세법 시행령) ③ 양도세 예정신고 기한(소득세법 §105) ④ 거주요건 2017-08-03 기산일·일시적 2주택 3년 완화·혼인 10년 확대의 각 **적용례 부칙** ⑤ 지방소득세 10%(지방세법 §103의3) — 해당 값 사용 시 경고 자동 출력.
- 재산세액 공제(종부세 §9③)·세부담상한(§10)은 **근사 산식**, 재산세 과세표준상한제(§110③)·재산세 세부담상한(§122)은 **미구현** — 실제 고지세액과 차이 날 수 있다.
- 입주권 양도차익의 관리처분인가 전/후 구분, 상속 선순위 주택 특정(어느 주택이 선순위인지), 감면(생애최초 외) 등은 단순화되어 있다 — 해당 경고 발생 시 legal-analyst·조사관과 협업.
- 10원 미만 절사 등 단수처리 미적용.

## 세율 갱신 절차 (법 개정 시)

1. law-api-query로 개정 조문 원문·시행일 확인.
2. `rules/*.json`의 값·`basis`·`verified`(확인일 포함) 갱신. 구법이 필요한 경과 사안은 값 교체가 아니라 날짜 분기 추가.
3. `tests/test_golden.py`에 개정 반영 케이스 추가 후 실행:
   ```bash
   python -m unittest discover -s .claude/skills/tax-calc/tests -v
   ```
4. CLAUDE.md 변경 이력에 기록.
