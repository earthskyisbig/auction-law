# 도메인별 쟁점 체크리스트

분석관이 쟁점 누락 없이 근거를 수집하도록 하는 점검표. 해당 도메인이 활성화되면 이 항목들을 훑어
질문과 관련된 것을 조사관에게 검색 지시한다.

## 경매
- [ ] 인수/소멸 권리 구분 (말소기준권리 이후 권리는 소멸, 이전은 인수)
- [ ] 유치권 신고 여부 및 성립요건(점유·견련성) — 판례 확인 필수
- [ ] 법정지상권 성립 가능성 (토지·건물 소유자 동일성)
- [ ] 대항력 있는 임차인 / 최우선변제 소액보증금 / 배당요구종기
- [ ] 당해세·조세채권 우선 배당
- [ ] 매각불허가 사유(민사집행법 §121·§123)

## 공매
- [ ] 압류·매각결정 절차 하자 여부
- [ ] 배분요구 및 배분순위
- [ ] 공매재산명세와 실제 권리관계 불일치
- [ ] 대항력 임차인 인수 여부 (경매와 처리 차이)

## 매매
- [ ] 계약금·해약금(민법 §565) / 위약금 약정
- [ ] 하자담보책임(§580) 범위·제척기간
- [ ] 토지거래허가구역 여부·허가 요건, 자금조달계획서
- [ ] 중개사 확인·설명의무, 중개보수 상한
- [ ] 임대차 승계(임대인 지위 승계)·선순위 임차인

## 재개발·재건축
- [ ] 조합원 자격(도정법 §39) — 다물권자·1+1, 세대 합산
- [ ] 투기과열지구 조합원 지위 양도 제한(§39②) 및 예외
- [ ] 분양신청 → 관리처분계획(§74) → 현금청산(§73) 흐름
- [ ] 현금청산 시 청산금 산정·이자, 협의/수용
- [ ] 정비구역 지정·해제, 이전고시·청산금 부과
- [ ] 소규모주택정비(가로주택 등) 해당 여부

## 청약
- [ ] 청약자격(무주택기간·부양가족·통장가입기간·거주요건)
- [ ] 순위·가점제/추첨제, 특별공급 유형별 자격
- [ ] 전매제한(주택법 §64) 기간·예외
- [ ] 공급질서 교란(§65) 및 부적격 당첨 처리·제재
- [ ] 재당첨 제한 기간

> 공통: 규제성 조항은 **시행일 기준**을 확인하고, 필요 시 `eflaw`로 특정 시점 법령을 조회한다.
