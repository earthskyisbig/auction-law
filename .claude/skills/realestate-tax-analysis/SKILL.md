# realestate-tax-analysis — 부동산 세무 분석

부동산 거래·보유의 세금을 **세법 근거로 산출**한다. 수익·의사결정에 직접 영향을 주므로, "대략"이 아니라 산식과 근거로 답한다.

## 분석 절차
1. **세금 이벤트 판별** — 취득/보유/임대/양도/상속·증여. 복수 가능(예: 취득+보유).
2. **납세자 구조 확정** — 개인 / 매매사업자 / 법인, 주택 수(세대 합산), 조정대상지역·투기과열지구 여부, 보유·거주기간.
3. **세목·세법 특정** — `references/tax-map.md`로 세목과 근거 세법·조문 지목.
4. **세액 산출** — 과세표준 → 세율 → 산출세액 → 감면/세액공제 → 부가세목(농특세·지방교육세)까지 단계 분리 계산.
5. **특례·절세·리스크** — 비과세·중과배제·특례 요건 검토, 놓치면 손해인 지점과 리스크 제시.

세목별 세율·공제·중과 표는 `references/rates-2026.md` 참조.

## 근거 우선 원칙 (핵심)
- 세법은 **개정·정책 변동이 잦다**(특히 다주택 양도세 중과 유예, 취득세 중과, 종부세 공제·세율). `references/rates-2026.md`는 **참고 기준값**일 뿐, 실제 판단 전에 `law-api-query`로 **해당 세법 조문·시행일·국세청/기재부 최신 예규(expc)**를 확인해 갱신한다.
- 세율·요건을 근거로 확인하지 못하면 "미검증 — 확인 필요"로 명시하고 임의 단정하지 않는다.
- **세율표·중과대상표가 조문이 아니라 별표에만 있는 경우**(예: 지방세법 시행규칙 별표) `law-api-query`의 `target=licbyl`로 **search만** 사용해 확인한다(body는 HTML 위젯만 반환하므로 호출하지 않는다 — 2026-07-27 실측). search 결과의 PDF/HWP 링크는 텍스트 파싱을 지원하지 않으므로, 수치 자체는 가능하면 조문(시행령 본문)에서 우선 확인하고 별표만 근거인 경우 사용자에게 원문 링크를 안내한다.
- **세금 다툼 사례(중과·비과세 부인 등 국세 불복)**는 `target=ttSpecialDecc`(조세심판원 결정례)로 실제 결정 사례를 확인할 수 있다 — `expc`(법령해석례)가 유권해석이라면 이쪽은 실제 분쟁에서 어떻게 판단됐는지 보여주는 1차 자료다.
- 금액 기준(취득가·양도가·기준시가·시가)이 불확실하면 시세·실거래 리소스(realprice-flow, apt-value)로 확인하거나 "가정값"으로 명시.

## 계산 표준 (투명성)
각 세목을 다음 단계로 분리해 보인다:
```
① 과세표준     (취득가액 / 양도차익 / 공시가격 등)
② 세율 적용     (기본세율 · 중과 여부 · 누진공제)
③ 산출세액
④ 감면·세액공제 (장기보유특별공제, 비과세, 특례)
⑤ 부가 세목     (농어촌특별세, 지방교육세, 지방소득세)
⑥ 총 부담세액   + 근거 조문/예규
```

## 재개발·재건축 세무 (법률팀과 연계)
- 조합원**입주권**은 관리처분계획인가일 전후로 "주택 → 입주권"으로 성격이 바뀐다 → 양도세 비과세·주택 수 산정에 결정적. 입주권 성립 시점은 legal-analyst의 판단과 정합을 맞춘다.
- 대체주택 비과세 특례(조특법), 청산금 과세, 원조합원 취득세(원시취득) 등 특유 쟁점을 `references/tax-map.md`에서 점검.

## 보고서 구성
```
1. 세금 이벤트 & 납세자 구조 요약
2. 적용 세목 개요(무엇이·언제·누구에게)
3. 세목별 산출내역(위 6단계 계산)
4. 비과세·특례·절세 포인트(요건 포함)
5. 리스크·주의(중과·정책 변동·기한)
6. 근거(세법 조문·예규 식별자) + 가정·확인 필요 항목
7. 고지: 참고용 세무정보이며 신고 전 세무사 확인 필요
```
