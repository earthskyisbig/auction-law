# citation-verification — 인용 사후검증 절차

작성이 끝난 문서(분석 보고서·위키 항목)에 인용된 조문·판례가 **실제로 존재하고, 원문과 일치하는지** 독립적으로
재확인한다. 작성자(legal-analyst 등)의 자기 검증과 달리, **검증자는 작성 과정에 관여하지 않은 상태에서
원문만 보고 판단**해야 확증편향을 피할 수 있다.

## 왜 별도 절차/에이전트로 분리했나
- 작성자가 스스로 검증하면 "내가 맞게 썼겠지"라는 전제가 판단에 스며든다. 실제로 korean-law-mcp의
  `verify_citations` 개발 과정에서도(§ `wiki/`와 무관, `_workspace/reference_comparison.md` §4.1 참조)
  법령명 부분일치·대용표현 오상속 같은 버그가 **자체 검증만으로는 걸러지지 않고** 별도 검증 로직에서 드러났다.
- 이 프로젝트도 처음엔 legal-analyst가 자기 보고서를 스스로 재조회하는 방식이었으나, "2차 시야가 없다"는
  구조적 공백이 있어 `citation-verifier`를 독립 에이전트로 분리했다(2026-08-10).

## 절차
1. **인용 추출**: 대상 문서(보고서 또는 위키 항목) 전체에서 다음 패턴을 뽑아 목록화한다.
   - 조문 인용: `법령명 제○조(제○항·제○호)` 형태. "같은 법", "같은 법 시행령/시행규칙" 같은 대용 표현은
     **직전에 명시된 법령명을 상속**한 것으로 해석해 전체 법령명으로 환원한다.
   - 판례 인용: `법원명 YYYY.MM.DD. 선고 사건번호` 형태. 문서에 판례일련번호가 병기돼 있으면 그것도 같이 기록.
   - 조세심판원·행정심판례·법령해석례 인용: 사건번호/일련번호가 있으면 함께 기록.
2. **재조회**: 각 항목을 `law-api-query` 스킬의 `scripts/law_api.py`로 **독립적으로 재조회**한다.
   - 조문: 문서에 적힌 MST/JO가 있으면 그것으로 `body --target law --mst <MST> --jo <JO>` 직접 조회.
     MST/JO가 없으면 법령명으로 먼저 `search`해 MST를 확정한 뒤 조회한다.
   - 판례: 문서에 일련번호가 있으면 `body --target prec --id <일련번호>`. 없으면 사건번호로 `search`.
   - **최신성이 중요하므로 `--no-cache`를 붙여 캐시를 우회한다** (검증인데 캐시된 옛 응답을 보는 건 무의미).
   - `[NOT_FOUND]`/`[ERROR:*]` 마커, 그리고 `{"Law": "일치하는 판례가 없습니다."}` 류의 정상-JSON-내용없음
     응답(2026-08-10 실측, `docs/ERRORS.md` 참조)까지 전부 "확인 불가"로 취급한다.
3. **판정** (문서에 이미 ✓/✗/⚠가 있어도 **무시하고 처음부터 다시 판정**한다):
   - **✓ 확인** — 재조회 결과가 문서에 인용된 조문 문언/판시요지와 일치.
   - **✗ 불일치·부존재** — 조·항이 없거나(개정으로 삭제·이동), 인용 문구가 원문과 다르거나, 조문 제목이 다르거나,
     법령명이 오매칭(예: "민법"이 실제로는 "난민법" 조문을 가리키는 경우)됐다.
   - **⚠ 확인 불가** — API가 본문을 제공하지 않는 판례(국세법령정보시스템 출처 등), 목록에서만 확인되고 본문
     대조는 못한 경우, 법령명이 모호해 완전히 확정하지 못한 경우.
4. **판례 생사 확인**: ✓ 판정된 판례라도, 해당 쟁점 키워드로 **최근 5년 이내 판례를 한 번 더 검색**해서 더
   최신 판례가 다른 취지로 나온 게 없는지 확인한다. 전원합의체 변경·파기 이력이 있으면 ✓ 판정이어도
   "⚠ 변경 이력 있음 — 최신 판례로 대체 필요"로 격하한다.
5. **보고서 작성**: 검증 대상 문서 경로, 항목별 판정표(원문 인용 vs 재조회 결과 vs 판정), 총평(PASS/FAIL/부분PASS)을
   담아 출력한다. **✗가 하나라도 있으면 FAIL**이며, 그 항목이 결론에 미치는 영향을 명시한다.

## 흔한 함정 (재검증 시 반드시 체크)
- 법령명 부분일치 오매칭 — "민법"↔"난민법", "주택법"↔"공동주택관리법" 등. **완전일치 우선**.
- "같은 법", "같은 법 시행령/시행규칙" 대용표현의 오상속 — 직전 법령명이 실제로 맞는지 문맥으로 재확인.
- 조문 번호는 맞는데 **조문 제목·항 번호가 다른** 경우 — 번호만 보고 넘기지 않는다.
- 판례 인용이 **사건명 필드만 있고 판시요지 본문은 확인 못한 경우**(정상 JSON, 내용 없음 케이스) — ✓로 격상하지 않는다.
- 세율·기준금액처럼 **시행일에 따라 달라지는 값**은, 조회 시점(오늘)이 문서 작성 시점과 다르면 개정 여부까지 재확인한다.

```
|---|---|---|---|---|
| 1 | 지방세법 제13조의2 제1항 | 원문 일치 확인 | ✓ | - |
| 2 | 대법원 2001다8677 전합 | [NOT_FOUND] API DB 미수록 | ⚠ | 인용문 자체가 2004다3598 판결이유 재인용임을 명시할 것 |
| 3 | 소득세법 제104조 제7항 (2025.1.1 기준 세율) | 현재 시행 조문과 %p 불일치 | ✗ | 2026.X.X 개정으로 세율 변경됨 — 갱신 필요 |
```
