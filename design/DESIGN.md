# 디자인 시스템 — auction-law

> 이 프로젝트의 모든 **웹앱 산출물(보고서·강의자료)**은 하나의 디자인 언어로 만든다.
> 기준: 강의 슬라이드 디자인(웜 크림 + 딥 네이비 + 오렌지 액센트).
> 매번 새로 디자인하지 않고 아래 토큰·컴포넌트·템플릿을 재사용해 일관성을 유지한다.
> 최초 생성: 2026-07-14

## 산출물은 웹앱(HTML)으로 만든다

| 산출물 | 만드는 법 | 출력 |
|--------|----------|------|
| **보고서** | `design/report-template.html` 복사 → 내용 채움 | 자체 포함 HTML → Artifact 게시 |
| **강의자료** | `docs/LECTURE.md`(7단) → `mk-slide-content`→`class_slide_apple` | 풀스크린 슬라이드 덱 HTML |

- 최종 산출물은 텍스트가 아니라 **웹앱(HTML)**으로 낸다 — 공유·발표·재열람에 유리.
- 모두 **완전 자체 포함**(외부 CSS/폰트/이미지 링크 금지) → Artifact CSP 안전. 자산은 인라인/data URI.

## 색상 토큰 (강의 슬라이드 기준)

| 토큰 | 값 | 용도 |
|------|-----|------|
| `--navy` | `#1c2b4a` | 히어로 배경, 표 헤더, 다크 요소, 헤딩 잉크 |
| `--ink` | `#26262e` | 본문 텍스트 |
| `--accent`(오렌지) | `#e2611f` | eyebrow 라벨, 아이콘, 카드 왼쪽 바, 화살표, 번호 배지, 강조 |
| `--cream` / `--paper` | `#f4f1ea` | 콘텐츠 배경(웜) |
| `--card` | `#ffffff` | 카드 배경 |
| `--muted` | `#6e6a75` | 보조 텍스트 |
| `--soft` | `#c9d6ee` | 네이비 위의 보조 텍스트/라인 |
| `--green` | `#2c7a4b` | 긍정·가능(세만틱) |
| `--red` | `#c0392b` | 리스크·불가(세만틱) |

- **오렌지가 유일한 브랜드 액센트**다. 강조는 오렌지에 몰고 주변은 조용히.
- green/red는 상태(state) 의미색으로만 쓰고 장식에 쓰지 않는다. 액센트(오렌지)와 구분.

## 시그니처 컴포넌트 (report-template.html 내장)
- **hero**: 네이비 배경 + 오렌지 eyebrow(대문자·자간) + 큰 흰 헤딩(오렌지 하이라이트 span 가능) + 크림블루 부제 + 필 칩. 우측 오렌지 원 그래픽(선택).
- **eyebrow**: 섹션 상단 오렌지 라벨. 그 아래 네이비 볼드 타이틀.
- **stepcard**: 화이트 카드 + **두꺼운 왼쪽 바**(오렌지 기본 / `.navy`·`.green`·`.red` 수정자) + 둥근사각 **아이콘 박스** + 크림 원형 **번호 배지** + 제목 + muted 본문.
- **flow**: stepcard들 사이 **오렌지 화살표(▶)**로 프로세스 표현.
- **table**: 네이비 헤더 + `.on` 행(크림/오렌지) 강조.
- **check**: 오렌지 체크박스 리스트.
- **disc**: 좌측 오렌지 바 고지/한계 박스.
- **footerbar**: 좌(프로젝트/강의명) · 우(날짜/페이지) 얇은 바.
- **theme toggle**: 우상단 라이트(크림)/다크(네이비) 전환.

## 필수 원칙
1. **라이트=크림 / 다크=딥네이비** 양 테마. 토큰을 `:root` + `@media` + `[data-theme]` 3중 정의, 컴포넌트는 토큰으로만.
2. **결론 먼저** — 요약/판정을 맨 위, 근거·상세는 아래.
3. **숫자·표 `tabular-nums`**, 넓은 표 `overflow-x:auto`.
4. **한글 본문은 시스템 스택**(AppleSDGothicNeo→Malgun Gothic 폴백). 웹폰트 data URI 인라인은 수 MB라 부적합.
5. **번호(01/02)는 실제 순서/절차일 때만.** 장식용 금지.
