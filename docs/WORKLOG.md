## 부딪힌 문제와 해결 ★
> 강의 하이라이트. 증상 → 원인 → 해결 → 교훈. (상세 로그는 docs/ERRORS.md)

- **law.go.kr 인증 = OC + IP 이중 검증**: OC(myung7788)가 맞아도 호출 서버 공인 IP를 사이트에 등록하지 않으면 "사용자 정보 검증 실패". 오류 msg의 "IP주소/도메인 등록" 문구가 결정적 단서. → `test` OC로 우회 조사, IP 등록 안내.
- **`search=2`(본문검색)는 target 불문 동작 안 함** — 처음엔 "test OC의 expc 제한"으로 오진했으나, 2026-07-15 등록 OC로 재검증하니 동일했고 prec에서도 "유치권 경매" → 음주운전 판례가 나왔다. **원인을 권한/OC 탓으로 성급히 결론내지 말고 대조군으로 반증해야 한다**는 교훈. 하네스 7곳의 "search=2 폴백" 지침을 전부 제거하고 **키워드 변형**으로 대체.

## 배운 것 / 교훈

- 법률 답변의 신뢰도는 **조문·판례 원문 인용**에서 나온다. 하네스 전체를 "근거 없는 서술 금지" 원칙 위에 설계.
- 공공 API 인증은 키(OC)뿐 아니라 **호출 IP 등록**이 함께 걸리는 경우가 많다 → 오류 메시지를 정확히 읽는 것이 우회의 시작.
- 에이전트 팀의 병렬 조사(법령↔판례)가 단독 조사보다 교차검증 품질이 높다.
